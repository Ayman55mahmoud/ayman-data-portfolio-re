# Ayman Mahmoud — Data Analyst Portfolio

A responsive bilingual (English/Arabic) portfolio built with plain HTML, CSS, and JavaScript. It is designed for GitHub Pages and requires no build step or backend.

## Publish with GitHub Pages
1. Create or open the repository `ayman-data-portfolio` on GitHub.
2. Upload the contents of this folder to the repository root (the `index.html` must be at the root).
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for deployment and visit `https://ayman55mahmoud.github.io/ayman-data-portfolio/`.

## Add or update a project
Edit `js/data.js` and add an object to `window.portfolioProjects`. Provide English and Arabic text, categories, tools, status (`completed`, `progress`, or `planned`), dataset notes, methodology, findings, deliverables, and real links. Add categories from `analysis`, `excel`, `sql`, `powerbi`, `python`, and `dashboards`. Project preview visuals are generated locally by JavaScript; replace these with real screenshots when available. Never present illustrative findings as real results.

## Contact links
Email and WhatsApp are set from the details provided. Replace social links or CV destination when you have the final URLs/files.

## Notes
- No framework or package installation required.
- Google Fonts is optional; local system fonts are used if the network is unavailable.
- Current project records are starter case-study templates. Update them with your actual datasets, validated findings, screenshots, and repository links before presenting them as completed work.
